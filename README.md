# Семейный счёт

Простой веб-калькулятор семейного бюджета: доходы, расходы, остаток и потенциальные накопления. Данные сохраняются локально в браузере.

## Что внутри

- **Лендинг** (`index.html`) — короткое приветствие и описание
- **Калькулятор** (`calculator.html`) — основной функционал
- Стили и скрипты вынесены в отдельные файлы

## Возможности

1. Ввод двух основных доходов и дополнительных поступлений
2. Добавление и удаление расходов
3. Автоматический расчёт дохода, расходов, остатка и накоплений
4. Прогресс-бар доли расходов от дохода
5. Подсказки по состоянию бюджета
6. Сохранение в `localStorage`

## Как открыть

Самый простой способ — открыть файл в браузере:

1. Перейдите в папку проекта
2. Откройте `index.html` двойным щелчком или через «Открыть с помощью» → браузер
3. Нажмите **Начать расчёт**, чтобы перейти к калькулятору

Либо через локальный сервер (если установлен Python):

```bash
cd урок
python -m http.server 5500
```

Затем откройте в браузере: http://localhost:5500
